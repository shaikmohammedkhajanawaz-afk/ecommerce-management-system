🛒 E-Commerce Management System

 📌 Project Overview

The E-Commerce Management System is a Java-based application designed to manage basic online shopping operations. It allows customers to register, log in, browse products, and manage their shopping carts. It also provides an admin login for managing product-related operations.

This project demonstrates core Java concepts, object-oriented programming, collections, and modular application development.

✨ Features

- Customer Registration** – Register new customers with their details.
- Customer Login** – Authenticate registered customers.
- Admin Login** – Provide administrator access.
- Product Management** – Manage product information.
- Shopping Cart** – Add and manage products in the cart.
- Input Validation** – Validate user inputs such as email and password.
- Menu-Driven Interface** – Navigate through the application using a simple console menu.

 🛠️ Technologies Used

- Programming Language:** Java
- Concepts:** Object-Oriented Programming (OOP)
- Collections:** ArrayList, HashMap
- Interface:** Console-based user interface
- Development Tools:** Eclipse IDE / VS Code
- Version Control:** Git and GitHub

 ⚙️ Prerequisites

Before running the project, ensure you have installed:

- Java JDK 8 or later
- Eclipse IDE or Visual Studio Code (optional)
- Git (optional, for version control)
 🚀 How to Run the Project

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Open the project in Eclipse IDE or VS Code.

3. Ensure the Java source files are in the correct packages.

4. Locate the `Main.java` file containing the `main()` method.

5. Run `Main.java` as a Java application.

6. Use the console menu to select the required operation.
